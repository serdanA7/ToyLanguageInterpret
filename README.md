🧸 ToyLanguageInterpret
Welcome to ToyLanguageInterpret, a Java-based interpreter for a custom-designed toy programming language. This project serves as an educational tool to explore the fundamentals of interpreters and language processing.​

🚀 Features
🧠 Custom Language Grammar: Implements a simple yet expressive grammar to understand language parsing.

🛠️ Interpreter Engine: Processes and executes code written in the toy language.

📄 Logging Mechanism: Generates detailed logs (log1.txt to log15.txt) to trace execution steps and debug.​
